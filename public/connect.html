🔌 Connect AI Rail

Enable the LensCrafter extraction tool inside Claude Desktop.

Step 1: Open Config

Open this file on your Mac:
~/Library/Application Support/Claude/claude_desktop_config.json

Step 2: Add Server

Paste this into the "mcpServers" object:

"lenscrafter": { "command": "npx", "args": [ "-y", "mcp-remote", "https://airail.io/mcp/messages?apiKey=YOUR_SECRET_KEY" ] }
Step 3: Restart Claude

Restart the app. Look for the 🔌 icon.
