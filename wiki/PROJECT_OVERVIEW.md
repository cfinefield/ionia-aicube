# Project Overview: aicube

## What is aicube?
`aicube` is a dynamic, 3D interactive user interface designed to host modular views known as "Lenses". It serves as the interactive presentation layer tightly integrated with backend AI services (the "AI Rail").

## Key Features
- **3D Interactive Space**: Uses a 3D cube metaphor (via `three.js`) to navigate and interact with different tools.
- **Lens Architecture**: Users engage with specific "Lenses" (e.g., ActionLens, TransactionLens) which handle specialized workflows and operations.
- **Generative AI Integration**: Powered by the LensCrafter Worker, it enables features like automated content extraction, structured data parsing, intelligent recommendations, and dynamically interfacing with repositories.
